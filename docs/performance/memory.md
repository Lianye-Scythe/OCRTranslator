# Windows 字型與記憶體優化紀錄

2026-11-06，本機 Windows 11 x64、Python 3.15.2、PySide6 6.12.0。數值是受控測試的 Private Bytes（MiB），不是 Windows 工作管理員所有頁面都使用的同一指標，也不是各台電腦的用量保證。

## 已採用的方案

- Windows 建立 QApplication 時預設使用 `windows:fontengine=gdi`，保留字型回退與彩色 emoji；已存在的 QApplication、明確的 `QT_QPA_PLATFORM` 設定及其他平台沿用原設定。
- 主介面、日誌與提示訊息繼承系統字型，移除固定的 Latin 字型列表。
- 浮窗繼續提供已安裝字型的選單；新設定優先 Noto Sans TC，缺少時選擇已安裝的 Noto CJK TC 或 Windows 中文字型。已存在且可用的字型選擇優先保留。
- 不附帶或下載字型檔。字型選擇不會讓 exe／ZIP 多出一套 Noto 字庫。
- 以向量繪製浮窗的減號和收合圖示，避開本機中文字型不包含這些符號時的大量回退配置。
- Markdown 程式碼先暫停文件排版，依等寬字型的實際字元覆蓋率分配字型，再恢復排版。未覆蓋的中日文字元使用浮窗字型，ASCII 程式碼維持等寬。位置使用 UTF-16 單位，以保留補充平面字元和後續文字的格式。
- 字型／字級變更即時套用到既有浮窗，保留結果與視窗位置；閱讀位置在 Qt 完成延遲排版後恢復。

## 量測發現

啟動四組對照各跑三個新程序：原版約 391.1 MiB；替換字型下拉選單約 391.2；停用預熱約 374.5。保留預熱、移除固定字型宣告約 72.2，因此保留預熱與字型下拉選單。

但只修改主介面不足以改善浮窗。浮窗第一次繪製的符號，以及含中日文的等寬程式碼，又能各自觸發額外約 300 MiB 配置。兩條路徑都納入此次修正。

完整主介面加浮窗、使用獨立設定、不註冊熱鍵／系統匣、不呼叫 API。每種字型各兩個新程序，顯示約 80 段繁中／日文假名／英文長文，再切換 Markdown、加入中日文程式碼，最後切換到另一字型再切回。

| 浮窗字型 | 啟動閒置 | 長文 | Markdown 與中日文程式碼 | 來回切換與提示訊息後 |
|---|---:|---:|---:|---:|
| Noto Sans TC | 72.5 | 77.2 | 77.2 | 74.6 |
| Microsoft JhengHei UI | 71.6 | 76.2 | 76.2 | 73.6 |

上述為各階段中位數；這些測試的總工作集約 111–123 MiB。字型來回切換未重新觸發原本約 390 MiB 的配置。先前主介面修正後的十次截圖測試，收尾約 81 MiB，未見線性成長；不是整個程式長時間無洩漏的證明。

## 補充回歸：浮窗缺字回退仍會暴增（2026-11-07）

使用者回報截圖／顯示翻譯浮窗後約 375 MB。已比對正在執行的 exe 與本機優化測試組建，SHA-256 完全一致；該程序實測 Private Bytes 約 392.5 MiB，設定為 Noto Sans TC、20 pt、Markdown 關閉。因此不能歸因於仍在使用舊組建。

以新 Windows 原生 Qt 程序、隔離設定重現，沒有呼叫 API：

| 操作 | Private Bytes（MiB） |
|---|---:|
| Noto Sans TC 浮窗，普通繁中／日文／英文 | 約 76 |
| 同一浮窗改顯示 `✅ ⚠️` | 約 393–395 |
| 同一浮窗只改顯示 `😀` | 約 391 |
| Microsoft JhengHei UI 浮窗顯示 `✅ ⚠️` | 約 390 |
| 單獨執行桌面截圖、框選畫面與預覽 | 約 75 → 123 → 96 |

截圖資料只保留在測試程序記憶體，沒有儲存或傳送。上述截圖階段數值不是高頻取樣的峰值。符號測試換回普通文字並隱藏浮窗後，Private Bytes 仍約 394.6 MiB；這次沒有看到立即釋放。

本機 QRawFont 字元覆蓋率檢查確認 Noto Sans TC 與 Microsoft JhengHei UI 都沒有 U+2705（✅）和 U+1F600（😀），Segoe UI Emoji 則有。Qt 在選定字型缺少字元時會自動尋找回退字型（[QFont 官方文件](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QFont.html)）。這條尚未處理的回退路徑可以重現同量級暴增；使用者該次翻譯中實際觸發的字元尚未逐字確認，不能把所有截圖後的增加都算成同一原因。

另以相同隔離浮窗停用字型合併作診斷對照，顯示符號、換回普通文字與隱藏浮窗，全程約 73.8 MiB，進一步確認配置與回退有關。這個對照可能造成缺字，僅用於診斷，沒有套用到產品。

另測得開啟手動輸入對話框約 71.7 → 390.2 MiB，完整語言選單仍須進一步隔離。單獨開啟／捲動字型選單約 74.6 → 77.7 MiB，該次沒有重現大量配置。

先前的測試漏了 emoji／特殊符號與手動輸入路徑，表格中的低用量不代表任意內容的上限。當時撤回可發布的建議；以下記錄後續修正與驗證；確認修正後納入 v1.0.16。

## 回退路徑修正與驗證（2026-11-07）

Qt 自 6.8 起在 Windows 預設使用 DirectWrite 字型後端，並提供 `fontengine=gdi` 選項（[Qt 6.8 變更](https://doc.qt.io/qt-6/whatsnew68.html)、[平台參數](https://doc.qt.io/qt-6/qguiapplication.html)）。本機對照中，僅指定 Segoe UI Emoji 並未避免大量配置；使用 GDI 字型資料庫後，同樣 `✅ ⚠️` 的浮窗約 76.3 MiB，字型合併仍然啟用。

修正套用在 `create_ui_application()` 的 Windows 預設啟動參數，沒有改寫文字內容或停用缺字回退。明確指定的 Qt 平台覆寫與其他平台不變。新程序測試確認 `A✅😀` 在可用的 Segoe UI、Noto Sans TC、Microsoft JhengHei UI 皆能產生三個非零字形，並實際使用不同字型完成回退；深淺色浮窗檢查可見彩色 emoji。

使用完整主視窗、實際截圖服務、串流回應呈現路徑、Markdown、兩種字型切換及手動輸入對話框，全部使用隔離設定及合成回應，不呼叫外部 API。各跑一個新程序，截圖僅留在記憶體；每次結果都包含繁中、日文、韓文、阿拉伯文、泰文、emoji 序列、數學符號與補充平面漢字。

| 階段 | Noto Sans TC／淺色 | Microsoft JhengHei UI／深色 |
|---|---:|---:|
| 啟動 | 72.6 | 72.4 |
| 混合文字串流 | 84.7 | 84.1 |
| 完成 Markdown | 84.3 | 84.0 |
| 開啟含語言選單的手動輸入框 | 84.7 | 84.4 |
| 連續十次截圖與結果後 | 88.6 | 87.6 |
| 隱藏浮窗並清除預覽後 | 85.0 | 84.0 |

單位為 Private Bytes（MiB）。50 ms 取樣的 Private Bytes 峰值約 140.3 MiB，總工作集取樣峰值約 189–192 MiB，包含截圖暫存；不是任意內容、所有電腦與長時間使用的上限。另一組包含更多罕用漢字的獨立浮窗測試收尾約 93.3 MiB，額外字型仍會有成本。

本輪 Windows 原生 GDI 模式 430 項測試通過，並使用 Python 3.15.2 完成 compileall。第一次完整執行曾有一項即時讀取系統剪貼簿失敗；該模組 41 項隔離重跑及隨後完整 430 項皆通過，未修改剪貼簿功能來略過檢查。Qt 平台覆寫與既有 QApplication 重用另有新程序測試。

本輪測試資料位於 `build/memory-analysis/fallback-flow-light.json`、`fallback-flow-dark.json` 及 `fallback-full-tests.stderr.log`。量測時使用的本機測試包版本號為 1.0.15；驗證完成後，修正納入 v1.0.16。清理本機組建暫存時可移除舊測試包，量測摘要與此紀錄保留。

新 PyInstaller exe 從 Windows 本機臨時目錄以獨立設定啟動，保留系統匣與臨時測試熱鍵，並在可見的設定檔名稱中放入 `✅ ⚠️ 😀`。約八秒後量到 72.6 MiB Private Bytes、116.2 MiB 總工作集。此檢查僅啟動與讀取程序指標；浮窗串流／Markdown／截圖驗證採上述原始碼測試，未透過桌面輸入或實際 API 操作封裝版。僅停止自己的測試程序與清理其臨時資料，未替換使用者正在執行的程式。

## 驗證與限制

- Windows 原生模式完整測試 428 項通過，另完成 compileall、文件連結及淺色／深色浮窗檢查。第一次完整測試曾有兩項系統剪貼簿即時讀取失敗；第二次同樣的原生完整測試全數通過，未修改複製功能來略過檢查。
- PyInstaller 單檔 Windows 組建完成，exe 約 56.7 MiB。從 Windows 本機臨時目錄啟動，保留系統匣和臨時測試熱鍵，主視窗閒置約八秒後量到 70.3 MiB Private Bytes、115.6 MiB 總工作集，正常關閉後 exit code 為 0。未包含字型檔或個人設定。
- 新設定預設 Noto 不會覆寫舊設定選擇；若原本儲存 Windows 字型，可從進階設定的結果字型欄位改選 Noto Sans TC。
- 讀取到的字型覆蓋率不代表全世界所有文字都能由該字型顯示。真正缺少的字元仍可能需要字型回退；不要用禁止合併字型換取缺字方框。
- Qt 字型快取不一定在切換後立刻釋放。用新程序比較字型配置，不以定時 EmptyWorkingSet 當作優化。
- 工作集下降不等於 Private Bytes 已釋放；本次自然閒置 60 秒沒有重現使用者先前的 360 → 60 MB。
- 量測資料與臨時測試工具位於本機被 Git 忽略的 `build/memory-analysis/`。數值不包含遠端服務品質、網路延遲、所有字型組合或不同 DPI／字型安裝環境的保證。
